Configuração de IA (Gratuito)

🔒 Sua chave é armazenada apenas no localStorage deste navegador. Nunca é enviada a nenhum servidor além da própria API.

📖

Tutorial: Como Obter Chaves de API Gratuitas

1. Groq (Opção Recomendada — Mais Rápida) 100% Gratuito

O Groq oferece velocidade extrema (centenas de tokens/segundo) com modelos Llama 3.3 70B sem custo algum.

  1. Acesse o console do Groq em console.groq.com.
  2. Crie sua conta ou entre diretamente com Google ou GitHub.
  3. No menu lateral esquerdo, clique na opção API Keys (ou acesse direto console.groq.com/keys).
  4. Clique no botão Create API Key.
  5. Dê um nome para sua chave (ex.: DocArchitect) e clique em Submit.
  6. Copie a chave gerada (ela começa com gsk_...). Guarde-a pois ela só aparece uma vez no console.
  7. Volte a esta aplicação, abra a tela Configurar IA, cole no campo correspondente e clique em Salvar.
2. OpenRouter (Modelos Abertos Gratuitos) Modelos :free

O OpenRouter disponibiliza modelos com cota gratuita diária (DeepSeek R1, Llama 3.3 70B Free, Gemini Flash Free).

  1. Acesse o site openrouter.ai.
  2. Clique em Sign In no topo direito e autentique-se com sua conta Google, GitHub ou e-mail.
  3. Acesse a página de chaves em openrouter.ai/keys.
  4. Clique no botão Create Key.
  5. Dê um nome para a chave (ex.: DocArchitect), deixe o limite de crédito padrão e clique em Create.
  6. Copie a chave gerada (ela começa com sk-or-...).
  7. Cole na tela Configurar IA desta aplicação e selecione um modelo com a etiqueta (Free).
🔒
Privacidade e Segurança: Sua chave de API fica gravada unicamente no localStorage do seu navegador nesta máquina. Nenhuma chave é enviada para servidores nossos, repositórios ou terceiros.
